O que é o CSS?

O CSS significa Cascading Style Sheets, ou Folhas de estilo em cascata

Sobre o CSS

Linguagem resoinsável por denifinir a aparência visual e organização dos elementos na tela.

Como aplicar o CSS?

Para aplicar o CSS, temos três abordagens:

  • CSS inline
  • CSS interno
  • CSS Externo
O que da para fazer com o CSS?

O CSS não serve apenas para colocar cor na página. Ele controla:

  • cores
  • fontes
  • tamanhos
  • espaçamentos
  • sombras
  • bordas
  • posicionamento
  • responsividade
  • animações
  • transições

Aplicando o CSS Inline

Nessa abordagem, o CSS é colocado diretamento no elemento HTML através do atributo style

Aplicando o CSS Interno

Nessa abordagem o CSS é aplicado dentro de uma tag < style > dentro do < head > do documento HTML.

Aplicando o CSS Externo

Nessa abordagem, os estilos do CSS ficam concentrados em um arquivo separado.

Para conectar esse aqrquivo ao HTML, utilizamos o elemento de < link > no < head > da página.
